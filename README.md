# Atelier PDF

Editor PDF care rulează complet în browser. Fișierele nu sunt trimise nicăieri.

- Text (cu diacritice), desen liber, evidențiere, dreptunghiuri, acoperire cu alb
- Semnătură desenată și imagini
- Completarea formularelor PDF
- Rotire, ștergere, reordonare pagini; unire PDF-uri; pagini goale

Deschide `index.html` în browser sau activează GitHub Pages pentru repository.
